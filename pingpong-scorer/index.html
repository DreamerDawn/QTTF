规则说明

赛制

  • BO3 / BO5 / BO7：三局两胜 / 五局三胜 / 七局四胜，先赢所需局数即结束，显示赛点。
  • 固定 K 局：无论比分一律打满 K 局（K 1–9），按胜局多者获胜；K 为偶数且胜局相同时判平局；固定 K 局不显示赛点，只显示局点。
  • 每局目标分默认 11，可选 7 / 21 或自定义 1–99。
  • 选手姓名：默认“选手A / 选手B”（双打为 A1/A2/B1/B2）。姓名框可完全清空重输；清空时界面以默认名回退显示，比赛开始时空位才补为默认名。

加球

  • 默认开启。以目标分 T 为例：开启时当双方达到 (T-1):(T-1) 平后，需领先 2 分者胜；关闭时先到 T 分者胜。
  • T=1 时先到 1 分胜（加球无意义）。
  • 加球阶段从该局第 2(T-1) 球之后开始，此阶段每 1 分换发；此前每 2 分换发。

发球与换边

  • 单打：每 2 分换发；进入加球阶段后每 1 分换发。每局结束后，下一局由上一局接发球方先发。
  • 双打：4 人固定循环 [先发球员 → 首先接发球员 → 先发球员搭档 → 接发球员搭档]，例如 A1 先发、B1 先接时为 A1 → B1 → A2 → B2。普通阶段每人连发 2 球；加球阶段每人只发 1 球并沿同一循环继续（A1→B1→A2→B2 交替）。接发方按固定顺序轮转。
  • 下一局：由上一局接发球队先发，其先发球员 = 上一局该队首先接发球员；接发球队 = 上一局发球队，接发球员 = 上一局该队首先发球员。
  • 换边提示：仅 BO 赛制的决胜局（最后一局），一方先到 ⌈T/2⌉ 时提示换边；换边不改变发球顺序，也不自动切换左右，只提示。固定 K 局不自动提示。另有“手动换边”按钮，仅切换左右显示，不影响数据。
  • 暂停与医疗暂停不影响发球轮换。

局点 / 赛点

  • 某方再得 1 分即赢本局时显示“局点（本局第 N 个）”；BO 赛制中某方再得 1 分即赢整场时显示“赛点（本场第 N 个）”。
  • N 表示该方拿到过的第几个“机会”，即有多少个来球可以让他赢下本局/本场。对方每救掉一个，下一个来球就是该方的再下一个局点：A 在 10:7 拿到第 1 个局点，被追到 10:8 就是第 2 个，10:9 是第 3 个。
  • 分方统计：A、B 各自独立计数，互不混算。
  • 被追平（如 10:10）后该方局点消失、停止累加；之后重新出现（如 11:10）则从第 1 个重新开始。
  • 若某方一路领先、中途从未出现“再 1 分即胜”的局面（如 11:5），则全程没有局点，计数为 0。
  • 固定 K 局不显示赛点。

暂停

  • 普通暂停：每方/每队每场 1 次（双打按队计），限时 60 秒；只能在死球状态请求（该局已有得分、下一球开始前；局间与本局 0:0 首球前不可请求）；请求后锁定计分并倒计时，倒计时到 0 只提示“可恢复比赛”并保持锁定，需点击“恢复比赛”解锁；可提前恢复。
  • 局间休息：每局结束后进入局间，显示 1 分钟倒计时（从上一局结束时刻起算）。局间不锁定计分，倒计时结束只是提示，随时可以开始下一局；局间时长不计入任何一局的单局时长，但计入总时长。
  • 医疗暂停：每方/每队不限次数、不限时；选择请求方后正计时，手动结束并记录开始/结束时间与累计时长（死球或局间均可请求）。
  • 两者都锁定计分，暂停期间总计时继续，单局时长包含该局内所有暂停，但不包含局间。

统计口径

  • 统计区提供“全场 / 单局”切换，单局可选局号；表格按 A / B 两列，双打按队伍汇总。全部统计由逐球记录自动计算，不手工维护，撤销 / 重置 / 刷新后保持一致。
  • Points won：该范围内该方总得分（全场为所有局之和）。
  • Biggest lead：该范围内该方曾达到的最大领先分差。单局取局内最大值；全场取各局单局最大值中的最大值，不按全场总得分差计算。
  • Points won / lost on own serve：该方在己方发球轮中的得分 / 失分。
  • Points won / lost on opp serve：该方在对方发球轮中的得分 / 失分。
  • Most consecutive points won / lost：连续得分 / 失分最大值。单局取局内；全场取各局单局最大值，不跨局累计。
  • Greatest deficit overcome：仅单局胜方统计，为该方在该局中曾落后的最大分差且最终获胜；若全程未落后记 0；负方记 0。全场取各局胜方该值的最大值。
  • Greatest lead against：按本计分器的默认定义——单局胜方在该局中曾建立的最大领先分差；若未领先记 0；负方记 0。全场取各局胜方该值的最大值。（名称保留，语义为正向领先；与上一条的区别在于“曾落后多少”与“曾领先多少”。）

时间口径

  • 总比赛时长：从“开始比赛”到比赛结束，正计时，包含局间、普通暂停、医疗暂停。
  • 单局时长：从该局开始到该局结束，包含该局内普通暂停与医疗暂停，不包含局间。局间不计入任何一局。

状态机与撤销

  • 状态：未开始配置 → 进行中 → 死球（每球得分后、下一球加分前）→ 普通暂停 / 医疗暂停（锁定计分）→ 局间 → 比赛结束。
  • 撤销上一球会同步回退比分、发球方 / 发球人、局点 / 赛点、局分、统计与图表；若该球导致局结束或比赛结束，撤销后恢复到该局 / 该场进行中。暂停记录与已用暂停次数不因撤销回退（重置比赛才恢复）。
  • 刷新页面自动从本地存储恢复当前比赛（比分、发球、计时、暂停次数、逐球记录、统计与已完成局图表）。只保存当前一场比赛，不提供历史比赛列表。

快捷键

  • A / ← A 方加 1 分；B / → B 方加 1 分；Ctrl+Z 撤销；P 普通暂停；M 医疗暂停；Esc 关闭弹窗。在输入框内输入时单键快捷键不生效。
